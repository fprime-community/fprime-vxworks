The purpose of these toolchain files is to serve as an example. Projects are expected to create their own `<toolchain>-vxworks.cmake` toolchain file in their project's repository. Project's should set `FPRIME_PLATFORM` to the name of their platform file (without the `.cmake`). Also note, this file will make use of the `VSB_HOME` and `WINDRIVER_COMPILER_ROOT` environment variables defined in your environment's .ini file. Make sure your project's `settings.ini` file points to the expected environemnt .ini file.
